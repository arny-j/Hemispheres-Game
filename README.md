# Hemispheres

**A first-person, narrative-driven fantasy adventure game developed using Godot 4.**

Hemispheres is a single-player adventure set in Panthea, a world divided between two opposing factions: Apollo, representing reason, and Dionysus, representing emotion.

The player takes the role of Cygnus, a traveller who must explore the world, uncover its history, interact with its inhabitants, and make decisions that influence the outcome of the conflict.

## Final Alpha — November 2026

This is the final Alpha version of Hemispheres, developed for the **GENR.7100 Final Project**.

The Alpha includes a complete main storyline and functioning gameplay systems. Some originally planned features have been simplified or deferred for future development.

## Download and Installation

The game is available for both **Windows and Linux**.

### Windows

1. Open the [Hemispheres Final Alpha Release](https://github.com/arny-j/hemispheres-game/releases/tag/v1.0-alpha).
2. Download `Windows-Build.zip` from the Assets section.
3. Extract the ZIP file to a folder of your choice.
4. Open the extracted folder.
5. Double-click the `.exe` file to launch Hemispheres.

Keep all extracted files together, as the game may require additional files included in the folder.

**Note:** Windows may display a security warning because the application is not digitally signed. Only run the game if you trust the source.

### Linux

1. Open the [Hemispheres Final Alpha Release](https://github.com/arny-j/hemispheres-game/releases/tag/v1.0-alpha).
2. Download `Linux-Build.zip` from the Assets section.
3. Extract the ZIP file to a folder of your choice.
4. Open the extracted folder.
5. Locate `Hemispheres-Alpha.x86_64`.
6. Double-click the executable to launch the game.

If the executable does not launch:

- Right-click `Hemispheres-Alpha.x86_64`.
- Open **Properties → Permissions**.
- Enable the option to allow the file to execute.
- Try launching it again.

**Important:** Keep the included `libterrain.linux.release.x86_64.so` file alongside the executable, as it is required by the Terrain3D system.

## Controls

| Action | Control |
|---|---|
| Move | W, A, S, D |
| Look around | Mouse |
| Interact / Continue dialogue | E |
| Dialogue choices | Mouse |
| Additional menus | Available through the in-game interface |

Other controls and options are available through the game's menus.

## Features

The Final Alpha includes:

- A four-act main storyline
- Two faction-related side quests
- Branching dialogue and player decisions
- Multiple narrative endings
- First-person exploration
- NPC interactions
- Quest tracking and objective navigation
- Quest and lore journals
- Basic environmental puzzles
- A faction relationship and progression system
- Save and load functionality with multiple save slots

## Development Status

Hemispheres is a completed educational Alpha rather than a fully finished commercial game.

The main narrative and core gameplay systems have been implemented and tested, including ten ending scenarios and save/load functionality.

Future development may include expanded storytelling, additional NPC interactions, more environmental detail, further puzzles, inventory functionality, and audio.
